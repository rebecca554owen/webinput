# WebInput

**豆包语音输入电脑版** - 利用手机端豆包输入法实现电脑端语音输入。

## 为什么需要 WebInput？

豆包输入法在手机端的语音识别准确率**远超其他同类产品**，但豆包电脑版尚未发布。加上台式机通常没有麦克风，无法直接使用语音输入。

**经过实际测试，强烈推荐使用豆包输入法进行中文语音输入：**

- ✅ **识别准确率极高**：对中文语音的识别准确率领先其他输入法
- ✅ **语义理解能力强**：能够准确理解上下文，减少误识别
- ✅ **标点符号智能添加**：自动识别语句结构，智能添加标点符号
- ✅ **支持多场景输入**：无论是日常对话、专业术语还是长文本输入，都能准确识别

WebInput 提供了一个优雅的解决方案：

1. 在电脑上运行 WebInput
2. 用手机扫描二维码
3. 在手机上使用语音输入完成内容
4. 点击"立即发送"，内容直接输入到电脑光标焦点位置

这样就间接实现了在电脑上使用语音输入的功能，无需等待电脑版输入法或购买额外硬件。

## 功能特点

- 📱 **手机端输入**：浏览器访问，无需安装 App
- ⌨️ **实时预览**：输入内容实时同步到桌面预览
- 🔗 **双向同步**：桌面端编辑可同步回手机端
- 👥 **多设备支持**：同时连接多台手机设备
- 📦 **单文件发布**：无需额外依赖，下载即用
- 🔄 **自动重连**：断线后自动恢复连接

## 系统架构

```
桌面端 (Wails)          WebSocket Hub          手机端 (浏览器)
    │                        │                      │
    ├─ 桌面端界面             │                      ├─ 输入界面
    ├─ WebSocket 客户端  ←───┼───────────→          ├─ WebSocket 客户端
    └─ HTTP 服务器           │                      └─ 实时预览
                             │
                    ┌────────┴────────┐
                    │   消息路由       │
                    │   设备会话管理   │
                    └─────────────────┘
```

## 消息协议

| 类型 | 方向 | 说明 |
|------|------|------|
| `preview` | 手机 → 桌面 | 预览输入内容 |
| `sync` | 桌面 → 手机 | 同步编辑内容 |
| `send` | 手机 → 桌面 | 确认发送到电脑 |
| `clear` | 桌面 → 手机 | 清空输入框 |
| `connect` | 客户端 → 服务器 | 连接声明 |
| `history` | 手机 → 桌面 | 添加到历史记录 |

## 开发

### 环境要求

- Go 1.25+
- Node.js 25+
- Wails CLI v2.11+

### 安装

```bash
# 安装 Wails CLI
go install github.com/wailsapp/wails/v2/cmd/wails@latest

# 安装前端依赖
cd frontend
npm install
```

### 运行

```bash
# 开发模式（热重载）
wails dev

# 生产构建
wails build --clean
```

## 使用说明

### 第一步：配置手机输入法（强烈推荐）

在开始使用之前，请先在手机上安装并配置**豆包输入法**：

1. 在应用商店搜索"豆包输入法"并安装
2. 在手机设置中将豆包输入法设为默认输入法
3. 开启语音输入权限

**为什么选择豆包输入法？**

- 中文语音识别准确率行业领先
- 自动智能添加标点符号
- 支持各种专业术语和长文本识别
- 语义理解能力远超其他同类产品

### 开始使用

1. 下载并运行 `webinput.exe`
2. 用手机浏览器扫描二维码或输入地址
3. 在手机上使用**豆包输入法**进行语音输入
4. 桌面实时预览识别结果
5. 点击"发送"按钮，内容输入到电脑
